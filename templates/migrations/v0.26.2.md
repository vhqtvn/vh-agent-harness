## Rollback
Reversibility: binary downgrade + re-render. Install a prior `vh-agent-harness`
binary (e.g. `v0.26.1`), then `vh-agent-harness update` (source-checkout repos:
`make update` against the prior tag). No data migration; no irreversible state.
Rolling back returns the doctor `dead-grants` messages to the unscoped wording
(the 7-vs-~30 reconciliation ambiguity re-opens), re-points the DEFER-promotion
DoR bullet at the engine-dead bare form, and leaves `docs/ai/shell-execution.md`
outside the prior corpus's managed set (the file may remain on disk, unmanaged —
delete it manually if you want the pre-v0.26.2 tree exactly).
