## §0 What hermes-agent IS.
A self-improving, multi-provider agent runtime/product (Python ≥3.11 core + TypeScript frontends: TUI/desktop/web/website), MIT, v0.20.0, Nous Research. NOT a repo-resident agent *harness* like vh-agent-harness. One `AIAgent` class (`run_agent.py:412`) serves all surfaces via a `platform` kwarg seam (`run_agent.py:435`). Sessions = SQLite + FTS5 with parent/child lineage (`hermes_state.py`). Two sacred properties in its `AGENTS.md`: (1) per-conversation prompt caching is sacred; (2) core is a narrow waist, capability at the edges.
